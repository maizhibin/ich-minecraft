# DTCoder Blocklands：非遗生存建造玩法设计

## 1. 产品定位

这是一款以体素探索、建造和工坊制作为基础的网页游戏。非遗内容不作为静态贴图或一次性收集品，而是通过“观察—学习—操作—制作—展示—传承”的循环进入玩法。

核心体验：

1. 探索体素世界和大型博物馆。
2. 在工坊向虚拟传承人学习工序。
3. 通过交互小游戏完成传统技艺。
4. 将完成的作品和知识档案带回博物馆。
5. 解锁新的建筑、展陈和后续技艺。

## 2. 设计原则

- **以技艺为中心**：展示知识、工序和传承关系，不只展示成品。
- **尊重来源**：每个项目保留名称、地区、类别、核心工序和资料来源。
- **先可玩再扩展**：第一期用两个闭环验证玩法，不一次堆叠大量百科内容。
- **与体素系统融合**：完成技艺后，世界必须产生可见变化。
- **不做投机化数字藏品**：作品只用于游戏内收藏、展览和建造。

## 3. 核心循环

```text
发现工坊
  → 阅读任务和文化背景
  → 完成简化但顺序正确的工序
  → 获得技艺印记
  → 世界中生成作品或建筑
  → 博物馆展陈进度提升
  → 解锁下一项技艺
```

## 4. 已实现范围

### 4.1 榫卯营造

位置：博物馆西侧榫卯台。

交互流程：

1. 选材
2. 墨线放样
3. 凿卯制榫
4. 试装校正
5. 合榫成架

玩家必须按正确顺序选择工序。完成后：

- 获得“木作营造”技艺印记。
- 博物馆旁生成一座木构示范门架。
- 博物馆进度增加。

说明：第一期是教学化抽象，不模拟具体流派或真实构件尺寸。后续应在专业人士指导下扩展斗拱、梁架和榫卯类型。

### 4.2 木活字印刷

位置：博物馆东侧印刷台。

交互流程：

1. 认识印刷文字需要反向排列。
2. 将“传承技艺”按镜像顺序排成“艺技承传”。
3. 完成上墨、覆纸和拓印。

完成后：

- 获得“木活字印刷”技艺印记。
- 博物馆新增印刷展陈。
- 玩家获得一张“传承技艺”印页记录。

### 4.3 成长型博物馆

博物馆界面展示：

- 总进度从 `0/4` 成长到 `4/4`。
- 已完成技艺及其作品。
- 未完成项目和对应工坊位置。
- 权威资料来源链接。

博物馆不是任务终点，而是玩家成果和学习记录的反馈中心。

### 4.4 茶园与传统制茶

位置：出生点左前方茶园和开放式茶馆。

教学化交互流程：

1. 种茶
2. 采摘
3. 萎凋
4. 杀青
5. 揉捻
6. 发酵
7. 烘焙
8. 在茶馆温器、注水并向 NPC 茶客奉茶

完成后：

- 获得“以茶待客”技艺印记。
- 茶馆新增待客茶席和茶园门架。
- 博物馆成长进度增加。

中国传统制茶包含绿茶、黄茶、黑茶、白茶、乌龙茶和红茶等不同类别，真实工序会因茶类与地方实践而变化。当前流程是便于理解的综合教学抽象，不应被视为单一茶类的标准生产规范。

### 4.5 中国皮影戏舞台

位置：出生点左前方、茶园北侧的木制戏台。

交互流程：

1. 选择人物、瑞兽或花鸟角色。
2. 连接肩、肘、腕等可动关节。
3. 将幕布背光调整到适宜范围。
4. 在时间轴中依次安排“登场、亮相、转身、谢幕”。
5. 点灯、击乐并完成演出。

完成后：

- 获得“灯影传情”技艺印记。
- 世界中的皮影戏台新增角色剪影展陈。
- 演出档案进入成长型博物馆。

真实中国皮影戏使用皮革或纸制彩色影人，通过操纵杆在背光幕布前表演，并结合音乐与演唱；不同传统的造型、唱腔和操纵方式并不相同。当前玩法只表达其基本构成。

## 5. 操作

- `WASD`：以角色视角为基准移动
- 鼠标：观察
- `Space`：跳跃
- `E`：上下文工坊交互。靠近工坊时直接进入对应项目；在博物馆内自动选择最近工坊；距离过远时显示路线提示
- `H`：从任意位置打开非遗图鉴与学习面板
- 页面右上角声音按钮：首次点击启动并试听，之后控制原创程序化 BGM 和全部音效
- `1—6` / 滚轮：切换方块
- 左键：放置方块
- 右键：破坏方块

## 6. 技术设计

### 世界层

- 工坊以确定性体素坐标生成，随区块加载。
- 技艺完成后通过世界事件写入方块修改表。
- 修改所在区块及边界相邻区块进入脏队列。
- 作品继续使用暴露面剔除和单区块合并网格。

### 界面层

- `VoxelGame` 管理 Three.js 世界和跨系统进度。
- `HeritageWorkshop` 管理榫卯、排字和博物馆档案交互。
- 高频渲染数据保存在 Three.js/Ref 中，React 只接收低频状态变化。
- 面板使用原生语义化按钮、进度和对话框属性，支持键盘操作。

### 工坊交互路由

- 两座工坊的直接交互半径为 7 个方块。
- 玩家位于博物馆范围内时，`E` 自动选择距离最近的工坊，避免必须站在单个精确坐标上。
- 玩家在博物馆外且距离工坊较远时，`E` 显示“前往右前方博物馆”的明确提示，不允许按键静默无响应。
- `H` 不受距离限制，承担图鉴、进度查看和远程学习入口。

### 音频系统

- 使用 Web Audio API 实时合成原创五声音阶氛围 BGM，不依赖外部音乐文件。
- 放置、破坏、跳跃、工序、奉茶、皮影动作和技艺完成均有独立音效。
- `AudioContext` 只在开始游戏、打开工坊或点击声音按钮等用户手势中创建或恢复。
- 声音按钮显示“待启用 / ON / OFF / 不可用”真实状态；启动成功后播放两声测试提示音，失败时给出检查标签页静音和输出设备的提示。
- BGM 与音效使用独立增益并针对桌面、移动设备扬声器提高可听音量。
- 用户可以随时静音，组件卸载时停止定时器并关闭音频上下文。

## 7. 验收标准

- [x] 掉头后，W 仍向视线方向前进，S 后退，A/D 相对角色左右移动。
- [x] 玩家接近榫卯台或印刷台时出现 `E` 提示。
- [x] 在博物馆内按 `E` 会自动进入最近的工坊。
- [x] 距离工坊较远时按 `E` 会出现路线提示。
- [x] `H` 可从任意位置打开非遗图鉴。
- [x] 榫卯工序顺序错误会提示并重置。
- [x] 榫卯完成后世界中生成木构门架。
- [x] 活字必须按镜像顺序排版才能拓印。
- [x] 四项技艺可分别完成且不会重复计数。
- [x] 制茶必须按七道工序完成，并在茶馆招待 NPC。
- [x] 皮影戏包含角色、关节、灯光和动作时间轴。
- [x] 茶园、茶馆和皮影戏台随区块加载并可碰撞交互。
- [x] BGM 只在用户交互后播放，并提供静音控制。
- [x] 放置、破坏、跳跃和非遗操作拥有反馈音效。
- [x] 博物馆进度和完成状态即时更新。
- [x] 桌面端与移动端均可打开和操作面板。
- [x] ESLint 与生产构建通过。

## 8. 后续路线

1. 龙泉青瓷：泥料、制坯、施釉和窑温曲线。
2. 中国剪纸：对称像素编辑器和窗花建材。
3. 南京云锦：经纬线与纹样编辑器。
4. 节庆事件：多人准备、装饰、表演和村落评价。
5. 将茶类、产区和加工差异拆分为经过专家复核的进阶路线。
6. 为皮影戏增加唱腔、乐器、多人操纵和地方流派档案。
