# 本机快速验收笔记（v1—v3）

不必全通关也可抽样：

1. `npm run dev` → 打开图鉴，确认进度分母为 **7**，可见青瓷 / 剪纸 / 云锦页签。  
2. 出生点向右前方沿沙径走到窑场，按 `E` 进入青瓷；走完窑温三段即可。  
3. 茶馆东侧剪纸案：可用「套用示意」快速验证入藏与世界窗花。  
4. 博物馆东南织机廊：穿经 + 套用挑花示意 + 投梭 + 校花。  
5. 刷新页面，确认已完成项仍在；清除进度后奖励回滚。  
6. `npm run lint` / `npm run build` / `npm test`。

权威链接已挂在各工坊页脚与 `README` 资料来源。
