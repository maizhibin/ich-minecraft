# v1 设计草案：龙泉青瓷

> 状态：草案，待 v0.5 验收通过后实现。  
> 资料优先引用 UNESCO / 文化和旅游部权威条目，实现前需再核对正式名称与工序表述。

## 定位

通过教学化窑场流程理解「泥 → 坯 → 釉 → 火」的技艺链条，而不是收集可交易瓷器。

## 建议世界落点

- 博物馆北侧或中央广场东延新建「龙泉窑场」体素场景（窑炉、晾坯架、釉缸）。
- 工坊交互半径保持 7；`E` 路由与博物馆最近工坊逻辑沿用现有系统。
- 在 `app/heritage/registry.ts` 新增 track：`porcelain`。

## 教学化工序（可玩抽象）

1. **备泥**：选择合适泥料比例（抽象选项，非真实配方）。
2. **制坯**：在简易外形中选择碗 / 瓶 / 盘之一并「修坯」。
3. **施釉**：选择釉色深浅档位。
4. **窑温曲线**：在升温 / 保温 / 降温三段中点选合理区间；错误则提示重试。
