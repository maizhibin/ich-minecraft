# v2 设计草案：中国剪纸

> 状态：草案，待 v1 完成后实现。

## 定位

用对称裁剪体验剪纸的基本方法，完成后作品进入博物馆，并可成为世界中的窗花展陈或建材。

## 建议世界落点

- 茶馆旁或博物馆侧廊新增剪纸案台。  
- 注册表 track：`papercut`。

## 教学化交互

1. 选择纸色与对称方式（左右对称 / 四折教学选项）。  
2. 在有限像素网格上点击「剪去」单元格。  
3. 展开对称预览，确认后入藏。

## 完成反馈

- 技艺印记：纸上乾坤  
- 世界奖励：建筑窗格出现窗花样式，或给予可放置的装饰方块（若新增方块类型，需同步纹理图集）  
- 博物馆档案 +1  

## 实现注意

- 独立组件，避免继续膨胀 `heritage-workshop.tsx`。  
- 提供撤销 / 重置；对称预览必须与裁剪结果一致。  
- 强调民俗实践与纹样含义简介，附权威来源。
