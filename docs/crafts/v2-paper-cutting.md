# v2 中国剪纸

> 状态：**已实现**（`app/heritage/crafts/papercut-craft.tsx`）

## 定位

用对称裁剪体验剪纸的基本方法，完成后作品进入博物馆，并在世界中出现窗花展陈。

## 世界落点

- 茶馆东侧剪纸案台，工坊坐标：`(-5.5, 8.5)`，track：`papercut`。
- 资料：[UNESCO 中国剪纸](https://ich.unesco.org/en/RL/chinese-paper-cut-00219)

## 已实现交互

选纸 → 对称方式 → 民俗问答 → 半边/一角像素剪刻（撤销/重置/套用示意）→ 展开相似度校验（≥80%）→ 修整（≥85%）→ 贴窗。

印记「纸上乾坤」。不做可交易藏品叙事。
