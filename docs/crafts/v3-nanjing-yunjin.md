# v3 南京云锦

> 状态：**已实现**（`app/heritage/crafts/yunjin-craft.tsx`）

## 定位

用经纬与纹样编辑理解云锦织造的基本逻辑，突出「寸锦寸金」的技艺与知识。

## 世界落点

- 博物馆东南织机廊，工坊坐标：`(48.5, -12.5)`，track：`yunjin`。
- 资料：[UNESCO 南京云锦木机妆花手工织造技艺](https://ich.unesco.org/en/RL/craftsmanship-of-nanjing-yunjin-brocade-00200)

## 已实现交互

识经纬 → 穿经 → 挑花 → 投梭 → 校花 → 上机。

印记「寸锦寸金」，织机廊生成纹样挂幅。
