# DTCoder Blocklands 迭代路线图

本文档约定接下来四个版本的目标、边界与验收方式。  
原则：**先打牢系统扩展能力，再按项增加非遗玩法；不把非遗做成装饰或可炒作藏品。**

## v0.5 · 系统奠基（本轮两小时任务）

### 目标

让后续三项非遗可以「登记配置 + 挂世界奖励 + 记进度」，而不必每次改散落在 `voxel-game.tsx` 里的硬编码。

### 本轮交付

1. **非遗注册表** `app/heritage/`  
   - 统一 track id、展示名、工坊坐标、引导文案、资料来源链接。  
   - 博物馆进度分子/分母由注册表长度推导，不再写死 `/4`。
2. **进度持久化**  
   - `localStorage` 保存已完成技艺。  
   - 刷新页面后进度与世界奖励可恢复。  
   - 提供「清除学习进度」入口（便于验收重置）。
3. **世界奖励配置化**  
   - 将榫卯/印刷/制茶/皮影完成后的方块写入抽到独立模块。  
   - 坐标与方块类型保持与现网一致，玩法结果不变。
4. **文档**  
   - 更新 `README.md`、`docs/ICH-GAME-DESIGN.md` 与本路线图。  
   - 附本轮验收清单。

### 明确不做（本轮）

- 不新增青瓷 / 剪纸 / 云锦玩法面板。  
- 不改动现有四项工序判定与交互流程。  
- 不引入新 npm 依赖。  
- 不做多人、不做服务端存档。

### 验收清单

- [ ] 完成任一技艺后刷新页面，进度仍为已完成，世界奖励仍在。  
- [ ] 清除进度后，四项均未完成，奖励方块不再出现（需重新完成）。  
- [ ] HUD / 博物馆进度显示为 `已完成数 / 注册表总数`。  
- [ ] 榫卯、印刷、制茶、皮影流程与完成反馈与改前一致。  
- [ ] `npm run lint` 与 `npm run build` 通过。

## v1 · 龙泉青瓷

### 玩法草案

位置建议：博物馆北侧或中央广场东延新建窑场体素场景。

教学化工序（可再与专家复核）：

1. 备泥 / 练泥  
2. 拉坯或修坯成形  
3. 施釉  
4. 窑温曲线（升温—保温—降温区间选择）

完成后：

- 技艺印记「青瓷窑火」  
- 世界生成窑炉或青瓷展架  
- 博物馆进度 +1，档案写入资料来源（UNESCO / 文旅部相关条目）

### 系统依赖

依赖 v0.5：在注册表新增 `porcelain`，挂奖励生成器与面板路由。

### 验收要点

- 窑温错误会提示并允许重试，不静默失败。  
- 桌面与移动端均可完成全流程。  
- 强调「技艺与窑火控制」，不做可交易藏品叙事。

## v2 · 中国剪纸

### 玩法草案

位置建议：茶馆旁或博物馆侧廊新增剪纸案台。

交互：

1. 选择纸色与对称轴（左右 / 四折等教学化选项）  
2. 在像素网格上「剪」出窗花样式  
3. 展开预览并确认入藏  

完成后：

- 技艺印记「纸上乾坤」  
- 获得可用作建造的窗花装饰方块（或世界窗格展陈）  
- 博物馆进度 +1

### 系统依赖

v0.5 注册表 + 可选新方块类型（若新增方块，需同步纹理图集与碰撞，仍遵守暴露面剔除规则）。

### 验收要点

- 对称预览正确，误剪可撤销或重置。  
- 作品进入博物馆档案，并可在世界中看见。

## v3 · 南京云锦

### 玩法草案

位置建议：博物馆东廊延伸织机工坊。

交互：

1. 认识经线 / 纬线角色  
2. 在简易纹样网格上按规则填色或挑花  
3. 完成一段教学纹样并「上机」确认  

完成后：

- 技艺印记「寸锦寸金」  
- 世界生成织机展陈或纹样挂幅  
- 博物馆进度 +1，资料链到权威来源

### 系统依赖

同 v1/v2；面板建议独立组件，避免继续膨胀 `heritage-workshop.tsx`。

### 验收要点

- 经纬规则错误有明确反馈。  
- 桌面与移动端可完成。  
- 叙事强调织造知识与传承，不做炒作藏品。

## 技术约定（跨版本）

- 新项目必须写入 `app/heritage/registry.ts`（或其后继配置）。  
- 世界奖励通过统一 `applyHeritageReward(track, setBlock)` 接口写入。  
- 高频渲染数据仍放 Ref / Three.js 对象，不每帧 `setState`。  
- 权威来源优先 UNESCO、文化和旅游部。  
- 每版结束跑 `npm run lint` 与 `npm run build`。

## v1—v3 验收清单

详见 [ACCEPTANCE-NOTES.md](ACCEPTANCE-NOTES.md)。

- [ ] 图鉴进度为 `n/7`，三项新页签可进入。
- [ ] 靠近窑场 / 剪纸案 / 织机廊按 `E` 可打开对应工坊。
- [ ] 青瓷窑温三段错误只重试当前段；完成后窑旁有展架。
- [ ] 剪纸可对照半边示意剪刻，相似度达标后贴窗；完成后案台有窗花。
- [ ] 云锦穿经/挑花/校花错误本步重试；完成后织机廊有挂幅。
- [ ] 刷新后进度与奖励仍在；清除进度后回滚。
- [ ] `npm run lint` 与 `npm run build` 通过。

## 本轮假设（若验收时需纠正请直接说明）

1. 存档仅用浏览器 `localStorage`，不做账号云同步。  
2. 「清除进度」会清技艺完成状态，并触发世界奖励回滚（通过重新加载时不再应用奖励）。  
3. v1–v3 的三项非遗选题沿用设计文档已列路线（青瓷 → 剪纸 → 云锦），顺序可在验收后调整。  
4. 本轮不拆分 `voxel-game.tsx` 的地形/物理主循环，只抽非遗相关配置与奖励，降低回归风险。
