# v3 之后可选方向

v0.5—v3 已落地七项非遗工坊。以下不阻塞当前验收，供后续迭代挑选。

## 玩法向

1. **节庆事件**：村落装饰、协作准备、简短表演与评价循环。  
2. **茶类进阶**：在专家复核后拆分绿茶 / 乌龙等差异路线。  
3. **皮影深化**：唱腔片段、乐器点选、地方流派档案。  
4. **青瓷进阶**：哥窑开片 vs 弟窑梅子青的对比教学关。

## 系统向

1. 将博物馆体素生成从 `voxel-game.tsx` 继续拆出。  
2. 工坊中途进度可选持久化（目前仅完成态落盘）。  
3. 移动端图鉴页签改为可横向滑动的芯片栏。  
4. 世界内简易路标方块，指向窑场 / 剪纸案 / 织机廊。

## 内容向

1. 每项工坊增加 30 秒「传承人讲述」文案页（仍挂权威来源）。  
2. 博物馆内为七项各设固定展柜编号，与档案页签对应。
