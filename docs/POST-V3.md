# POST-V3 落地说明

v0.5—v3 七项非遗工坊之后的可选方向，已在本轮基本落地。下文对照原清单。

## 玩法向

1. **节庆事件**：档案页「村落节庆」演练（挂彩→备席→短演→评价）；不计入七项进度；完成后广场点亮灯笼式展陈（`festival-complete` / `applyFestivalReward`）。
2. **茶类进阶**：开局可选绿茶（略过发酵、口味答清香）/ 乌龙（保留发酵、答醇厚）。
3. **皮影深化**：排练后增加唱腔片段、击乐点选、地方流派档案，再开演。
4. **青瓷进阶**：装窑后可选哥窑开片 / 弟窑梅子青，开窑验坯标签随路线变化。

## 系统向

1. 博物馆体素与七项展柜编号抽至 `app/heritage/museum-world.ts`。
2. 工坊中途 `phase` 草稿与完成态一并落盘（`drafts`）；节庆完成记 `festivalDone`。
3. 移动端页签改为横向可滑动芯片栏（`.heritage-chip-scroll`）。
4. 世界路标与砂石小径仍在 `world-sites.ts`（窑场 / 剪纸案 / 织机廊）。

## 内容向

1. 每项工坊进入工序前可读「传承人讲述」页（`craft-narrator` + `craft-lore`）；有草稿或已完成则跳过。
2. 博物馆七项展柜编号与档案页签 `01`—`07` 对应，图鉴侧栏可对照。
